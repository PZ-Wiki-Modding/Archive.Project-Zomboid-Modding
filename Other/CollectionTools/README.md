The `export.py` script allows for converting between a Project Zomboid mod list (with game mod ids) and Steam workshop id list.
The `append.py` script allows for adding a list of workshop items to a collection.

### Requirements

- Python 3.13 or higher
- uv (install guide [here](https://docs.astral.sh/uv/#installation))

### Usage

```sh
uv sync
uv run <script>
```
